# Project Organization

## Core Projects
- **SamWaf**: A web application firewall, designed to protect web applications from attacks. (Programming Language: Go)
- **SamWafWeb**: The web interface for managing SamWaf configurations and monitoring traffic. (Programming Language: HTML/CSS, JavaScript) 

## Tools & Utilities
- **BatchJarSource**: A tool for managing batch processing of JAR files. (Programming Language: Java)
- **SamWafIpMonitor**: Monitor and log IP address activities related to SamWaf. (Programming Language: Go)
- **proxy_protocol_tester**: A tool for testing proxy protocol implementations. (Programming Language: Go)
- **JSBeautifier**: A tool for beautifying JavaScript code for better readability. (Programming Language: JavaScript)

## Infrastructure 
- **cap_go_server**: A server for managing CAP (Common Alerting Protocol) messages. (Programming Language: Go)
- **RemoteKnown**: A remote management utility for SamWaf instances. (Programming Language: Go) 

## Data & Knowledge
- **SamWafBotIPDatabase**: A database that tracks known bot IP addresses and their activities. (Programming Language: Go) 

## Documentation & Testing 
- **docs**: The official documentation for all projects associated with SamWaf. (Programming Language: Markdown)

## Monitoring & Notifications
- **SamWafWinEvent**: A tool for monitoring Windows events related to SamWaf. (Programming Language: Go)
